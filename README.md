# 獺郷太鼓連 お手本（LP）

印刷した譜面の QR コードから開く、**お手本動画のリンク集**です。
ファイルは `index.html` **1つだけ**。ビルド不要・外部の読み込みなしで動きます。

```
屋台囃子  ← 押すと開く
   ① ぶっつけ   [小太鼓] [大太鼓]   ← 押すと YouTube のその場面から再生
   ② 地         [小太鼓] [大太鼓]
   …
   通しで見る
```

曲を増やしても同じ形で並びます。

**現在の動画**: https://www.youtube.com/watch?v=Ej1aBPrE3qo （限定公開・10分50秒）

> 短縮形の `youtu.be/…` は使いません。リダイレクトのときに
> **`t=`（開始位置）が落ちることがある**ためです。

---

## 動画

**1本の動画の中に、小太鼓・大太鼓・通しが順に入っています**（全10分50秒）。

```js
var VIDEOS = {
  otehon: { id: 'Ej1aBPrE3qo', note: '屋台囃子 お手本（10分50秒）' }
};
```

| 中身 | 動画の中の位置 | 元ファイル |
|---|---|---|
| 小太鼓（①〜⑥ラベル入り） | 0:00 〜 2:44 | `yatai_1.mp4` |
| 大太鼓（①〜⑥ラベル入り） | 2:44 〜 6:31 | `yatai_2.mp4` |
| 通し | 6:31 〜 10:50 | `yatai_3_toshi.mp4` |

URL が `https://youtu.be/AbCdEfGh123` なら、ID は **`AbCdEfGh123`**。
（`https://www.youtube.com/watch?v=AbCdEfGh123` の `v=` のうしろも同じものです）

> **公開設定は「限定公開（Unlisted）」にしてください。**
> URL を知っている人は誰でも見られます。QR から来た人も見られます。
> **「非公開（Private）」だと本人しか見られません。**QR を読んでも再生できません。

ID が空のあいだは、そのボタンは点線の「押せない見た目」になり、
ページの上に「準備中です」と出ます。**リンク切れにはなりません。**

## ①〜⑥ のタイムスタンプ

`SONGS` の `at` に書いてある秒数です。**動画の頭からの位置**なので、
大太鼓は 2:44（164秒）を足した数になっています。

| | 小太鼓 | 大太鼓 |
|---|---|---|
| ① ぶっつけ | 0:00 | 2:44 |
| ② 地 | 0:18 | 3:03 |
| ③ かえ違い | 0:34 | 4:22 |
| ④ 乱拍子 | 1:02 | 4:50 |
| ⑤ 刻み | 1:58 | 5:43 |
| ⑥ 切り | 2:33 | 6:20 |
| （通し） | | 6:31 |

⑥だけ実際の頭（2:36 / 6:23）より3秒早いのは下の「⑥切りだけ〜」のとおりです。

出しかたは「`ffprobe` で元クリップの尺を測って足す」、
検証は「焼き込まれたラベルの目視確認」と「輝度による実物との突き合わせ」です。
（詳しい記録は手元のノートにあります）

**動画をつなぎ直したら、この数字も直してください。**

## YouTube の説明欄（チャプター）

`youtube-説明欄.txt` の中身を、YouTube Studio の「説明」欄に貼ります。
再生バーが区間に分かれ、飛んだ先に節の名前が出るようになります。

> **チャプターを付けても、飛び先の URL は変わりません。**
> このページのボタンは `?t=秒` を指しており、チャプターの有無に関係なく動きます。
> チャプターは「YouTube 側で見たときの分かりやすさ」のためだけのものです。

### ⑥切りだけ実際より3秒早い

YouTube は **すべての章が10秒以上**でないと、1つでも短いと
**動画全体で章が出なくなります**。

⑥切りは実際には8秒しかない（小太鼓 2:36〜2:44 / 大太鼓 6:23〜6:31）ため、
**開始を3秒早めて11秒を確保**しています。

| 節 | 実際の頭 | 章とボタン |
|---|---|---|
| 小太鼓 ⑥切り | 2:36 | **2:33** |
| 大太鼓 ⑥切り | 6:23 | **6:20** |

⑤刻みの最後が少し入りますが、聞くうえでは問題ありません。

**ページのボタンと説明欄の章は、13か所すべて同じ時刻**にしてあります。
飛んだ先でその章が選ばれた状態になるためです。
**片方だけ直すとずれます。**

**節を足したり動画をつなぎ直したときは、章が10秒を切っていないか確かめてください。**

## 公開する（GitHub Pages）

印刷した QR は後から直せないので、**URL が変わらないこと**が何より大事です。
GitHub Pages はリポジトリ名を変えないかぎり URL が変わりません。

1. GitHub で新しいリポジトリを作る（例：`osogoutaikoren-otehon`）
   - **Public** にする（Private だと Pages が使えません）
2. このフォルダを push する

   ```bash
   git init
   git add -A
   git commit -m "獺郷太鼓連 お手本ページ"
   git branch -M main
   git remote add origin https://github.com/<あなたのID>/osogoutaikoren-otehon.git
   git push -u origin main
   ```

3. リポジトリの **Settings → Pages** を開く
   - Source: **Deploy from a branch**
   - Branch: **main** / **/ (root)** → Save
4. 1〜2分待つと、この URL で公開されます

   ```
   https://<あなたのID>.github.io/osogoutaikoren-otehon/
   ```

5. **その URL を実際にスマホで開いて確かめてから**、QR を作ります

更新したいときは、`index.html` を直して push するだけです。

> `index.html` に `<meta name="robots" content="noindex">` を入れてあります。
> 検索には出ませんが、**URL を知っていれば誰でも見られます**（QR から来た人のため）。
> 見られては困るものは載せないでください。

## 中身を増やす

`index.html` の下のほうの3か所だけです。

### 曲を増やす

`SONGS` に同じ形のものを足します。

```js
var SONGS = [
  { name: '屋台囃子', /* … */ },
  {
    name: '大杉囃子',
    hint: '①〜④ からえらべます',
    sections: [
      { num: '①', name: '…', at: { kodaiko: 0, odaiko: 120 } }
    ],
    full: { video: 'otehon2', at: 0, label: '通しで見る', note: 'さいしょから おわりまで' }
  }
];
```

### 動画を増やす

`VIDEOS` に足してから、`PARTS` の `video` や `full.video` でその名前を使います。

### パート（小太鼓・大太鼓）を増やす

`PARTS` に足します。ボタンはこの配列の順に並びます。

```js
var PARTS = [
  { key: 'kodaiko', video: 'otehon', label: '小太鼓' },
  { key: 'odaiko',  video: 'otehon', label: '大太鼓' },
  { key: 'fue',     video: 'otehon', label: '笛' }
];
```

- `key` … `SONGS` の `at` で使う名前
- `video` … どの動画を見るか（`VIDEOS` の名前）

**いまは1本の動画に全部入っているので `video` はどれも同じ**ですが、
パートごとに別の動画にしたくなったら `video` を変えるだけです。

**その曲にそのパートが無いときは、`at` にその `key` を書かなければ
ボタンが出ません。**空欄を作る必要はありません。

## 手元で開くときは `Chromeで開く.bat`

**Claude Desktop のプレビュー画面では、ボタンを押しても正しく飛びません。**
プレビューがリンクを既定ブラウザへ渡すときに `?v=…&t=…` を落とすため、
YouTube のトップページが開いてしまいます。

確認ダイアログに出る URL が `https://www.youtube.com/watch` で
止まっていたら、これが起きています。**ページ側は正常です。**

`Chromeで開く.bat` をダブルクリックすれば Chrome で開き、正しく動きます。
GitHub Pages に上げたあとは、ふつうに URL を開けば問題ありません。

> このバッチは **Shift-JIS(CP932)** で保存してあります。
> UTF-8 で保存し直すと、日本語の行で cmd が止まります。

## 「直したのに変わらない」とき

**ブラウザが古い版を覚えています。**`file://` で開いていてもキャッシュされます。

1. ページのいちばん下に出ている日付（例 `2026-08-16 b`）を見る
2. 直したはずの日付と違えば、古い版を見ています
3. **`Ctrl` + `Shift` + `R`**（強制再読み込み）

日付は `index.html` の `VERSION` で変えます。**中身を直したら一緒に変えてください。**

---

## 直すときに気をつけること

- **`<summary>` に `display: flex` を掛けない。**
  `display: list-item` でなくなると、Chrome が「開閉できる要素」という
  意味づけを落とし、読み上げで開けることが伝わらなくなります。
  中身を横に並べたいときは、中の `.summary-row` 側で flex にします
- **リンクは `www.youtube.com/watch?v=ID&t=秒s` の形。**
  末尾の `s`（秒）まで含めた形にしています。作っているのは `urlAt()` の1か所だけです
- **ボタンの時刻と説明欄の章の時刻を必ず揃える。**
  ずれていると、飛んだ先で1つ前の章が選ばれた状態になります
- 動画が無いときは、リンクではなく**押せない `span`** を出しています。
  リンク切れを踏ませないためです
